12. HOME PAGE

Original file: home .html

Isko rename karke: home.html

Location: templates/website/home.html

Home page mein top par: {% load static %}

add kiya.

Local CSS paths ko Django static format mein convert kiya.

Example: href=“css/style.css”

becomes: href=“{% static ‘website/css/style.css’ %}”

JS: src=“js/bootstrap.js”

becomes: src=“{% static ‘website/js/bootstrap.js’ %}”

Image: src=“images/logo.png”

becomes: src=“{% static ‘website/images/logo.png’ %}”

22. COMMON DJANGO RULES

Static files: {% load static %}

CSS: {% static ‘website/css/file.css’ %}

JS: {% static ‘website/js/file.js’ %}

Images: {% static ‘website/images/file.jpg’ %}

Internal Django page: {% url ‘home’ %}

Another named Django page: {% url ‘laboratory_methods’ %}

Template inheritance later: {% extends “website/base.html” %}

23. TROUBLESHOOTING

If Home works but another page gives an error: - Check website/urls.py -
Check website/views.py - Check template filename - Check {% url %}
name - Run: python manage.py check

If CSS/images do not load: - Check {% load static %} - Check static file
location: static/website/css/ static/website/js/
static/website/images/ - Check exact filename and extension.

If a link tries to open .html directly: - Replace direct HTML link with
Django {% url %}.
