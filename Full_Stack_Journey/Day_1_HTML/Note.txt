<!DOCTYPE html>
Browser ko batata hai ki ye HTML5 document hai.

<html lang="en">
Ye poore HTML document ka root element hai. lang="en" batata hai ki page ki primary language English hai.

<head>
Yahan webpage ki information/settings hoti hain jo normally page par directly दिखाई नहीं देतीं.

<meta charset="UTF-8">
Text/characters ko properly display karne mein help karta hai.

<meta name="viewport" content="width=device-width, initial-scale=1.0">
Mobile devices par webpage ko properly scale karne mein help karta hai.

<title>My First Website</title>
Browser tab mein title dikhata hai.

<body>
Jo content user ko webpage par dikhega, woh mostly yahan hota hai.

<a href="https://www.google.com">Google</a>
a = anchor
href = link ka destination
Google = user ko dikhne wala text

<table> → poori table
<tr> → table row
<th> → heading cell
<td> → normal data cell
