# Foodie — Food Ordering Website (Frontend Demo)

## Tech stack
HTML5, CSS3, JavaScript (DOM manipulation, localStorage), Bootstrap 5.

## Pages
- `index.html` — Home and featured dishes
- `menu.html` — Category filtering and add-to-cart
- `about.html` — About page
- `contact.html` — Client-side form validation
- `cart.html` — Quantity controls, subtotal and demo checkout

## Run locally
Open `index.html` in a browser. Bootstrap and food photos load from the internet, so an internet connection is recommended.

## Notes
This is a frontend portfolio project. Cart data is saved in browser `localStorage`. Contact form and checkout are demonstrations only; no backend, real order processing or payment gateway is connected.
